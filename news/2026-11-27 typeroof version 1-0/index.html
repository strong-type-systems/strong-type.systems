#TypeRoof Version 1.0 Release and ATypI Sharjah

TypeRoof is entering a new development phase and Lasse will present it at the ATypI conference in Sharjah, UAE.

#The Release

Read the original Release Note of TypeRoof Version 1.0.0 and make sure to visit the new project home page for directions: TypeRoof.

#ATypI Sharjah, October 28–31, 2026

Lasse will be presenting TypeRoof in two different sessions:

  • The Demo Workshop: TypeRoof: A Hands-on Demo of Tools for Variable and Parametric Fonts Wed, October 28, 2026, 14:00 – 16:00
  • The Demo Presentation: Beyond the Slider: Building a Parametric Typography Ecosystem with TypeRoof Fri, October 30, 2026, 12:00 – 12:30

If you happen to be in Sharjah, be sure to join!
